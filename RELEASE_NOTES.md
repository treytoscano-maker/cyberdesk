# Cyberdesk 3.7.0 · personalization preview

- Click screenshots/images for an in-app preview, with previous/next navigation.
- Drag file tiles or preview images out using native file drags instead of text IDs. Use Arrange tiles for internal reordering.
- CUSTOMIZE → Edit cards & shortcuts creates custom cards, edits shortcuts and renames shortcut cards. Select custom cards per monitor in CARDS.
- Right-click Desktop tiles to edit Cyberdesk labels/groups; originals stay in place. Configuration saves keep backups.
- The reusable workflow prompt now supports custom cards and virtual Desktop organization.

Apple Silicon app and source starter downloads are included. Start with README.md and Customize-Cyberdesk-Prompt.txt. Local Swift/configuration/file-transfer and interface regression checks passed. End-to-end dragging into chat, Apple Music playback, Intel and other macOS versions still need acceptance. This is an early preview, locally signed and not notarized. macOS may block downloaded apps; source build is the supported fallback. No private configuration, keys, client files or desktop screenshots are included.
