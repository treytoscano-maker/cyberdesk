# Desktop 4.0 · new name, same workspace

Cyberdesk is now **Desktop**. The app name, window/menu labels, build script, setup prompt, repository and download names have been updated.

Existing settings, per-monitor layouts, cards, wallpaper gallery and restoration records are preserved by retaining the previous internal identifiers and storage locations. No personal files are moved by the app rename. Personal wallpapers and private configurations remain excluded from public downloads.

Includes the visual card editor, native image previews/file dragging, per-monitor card selection, personal wallpaper gallery and matching palettes, and optional adaptive local video backgrounds.

Apple Silicon app and source starter included. This is an early preview, locally signed and not notarized; macOS may block downloaded copies. Source build is the supported fallback. Read README for compatibility, restoration and resource-use limitations.
